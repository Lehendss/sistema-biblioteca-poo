Actividad Semanas 1 y 2: POO, UML, Herencia y Composición
Objetivo
Integrar los aprendizajes desarrollados durante las semanas 1 y 2 mediante el modelado UML y la implementación de soluciones utilizando los principios fundamentales de la programación orientada a objetos.

Actividades a realizar
Semana 1: Clases, objetos, encapsulación y UML
Elaborar el diagrama UML
Implementar las clases aplicando encapsulación, incluyendo atributos privados y métodos getters/setters.
Implementar la solución en Python o Java.
Semana 2: Herencia y composición
Elaborar el diagrama UML de la solución.
Implementar las clases las cuales deben heredar de las clases creadas en la semana 1
Desarrollar la solución en Python o Java.
Entrega
Realizar una sola entrega en Blackboard que contenga:

Un archivo PDF con los datos del estudiante, una breve explicación de la solución implementada y el/los diagrama(s) UML.
El archivo PDF debe contener el enlace a un repositorio público de GitHub que contenga el código fuente desarrollado en Python o Java.
Se recomienda nombrar el archivo PDF de la siguiente manera:

Apellido_Nombre_Semanas1y2.pdf

El código entregado debe ser funcional y el estudiante debe estar en capacidad de explicar su funcionamiento.
